Nikita Kothari - Portfolio Website
==================================

HOW TO OPEN (30 seconds)
1. Save the attached ZIP file (nikita-portfolio.zip) to your computer.
2. Unzip it:
   - Windows: right-click the ZIP > "Extract All..." > Extract.
   - Mac: double-click the ZIP.
3. Open the new "nikita-portfolio" folder.
4. Double-click "index.html". It opens in your web browser (Chrome, Safari, Edge or Firefox). No internet or installation needed for the page itself.

IMPORTANT
- Do NOT open index.html from inside the ZIP preview. Unzip first, otherwise the photo will not show.
- Keep index.html and nikita.jpg in the same folder.

FILES
- index.html : the complete website (one file)
- nikita.jpg : profile photo
- README.txt : these instructions

TO PUT IT ONLINE (optional)
Drag the "nikita-portfolio" folder onto https://app.netlify.com/drop (free) to get a public link you can share.
